
# MAD Practical – 5 : Login & Registration using Jetpack Compose

This Android application demonstrates the implementation of **Login** and **Registration** screens using **Jetpack Compose**, Android’s modern UI toolkit.  
It is part of the Mobile Application Development curriculum and focuses on understanding Compose UI components, state management, input validation, and navigation.

---

## 📌 AIM
Create an Android application that includes Login and Registration screens using **Jetpack Compose**.

---

## 📚 Study Reference
**Jetpack Compose Course**  
(Used for understanding Compose components, state handling, navigation, and UI design patterns.)

---

## ✨ Features

- Modern UI built entirely with **Jetpack Compose**.
- User-friendly **Login Screen** with input fields and validation.
- **Registration Screen** allowing users to create a new account.
- Smooth navigation between Login and Registration screens using `NavController`.
- Proper state handling for form validation and UI updates.
- Clean and modular Compose functions.
- Optional password visibility toggle.
- Reusable composables for text fields and buttons.

---

## 🚀 How to Use

1. **Launch the App**  
   The Login screen appears first.

2. **Login**  
   - Enter your email and password.  
   - Tap the **Login** button.  
   - If the fields meet validation rules, the app proceeds (you can navigate to a home screen or show a success message).

3. **Go to Registration**  
   - Tap **"Create Account"** or similar link/button.  
   - You’ll be navigated to the Registration screen.

4. **Register**  
   - Enter required details such as name, email, and password.  
   - Tap **Register** to simulate or store user account creation (depending on your implementation).

5. **Navigate Back**  
   - Return to the Login screen using the UI navigation options.
